Turns what Patina makes into files. `MeshMapBakeRun` is a bake from paths to files, for the Worker and `patina bake-maps`. `Presets` reads export presets, which are data: a factory set in `content/export-presets` and whatever a library keeps in `shared/export-presets`. `ChannelPacker` fills a file's lanes, and is the one place green turns over and a number moves between sRGB and linear. `ExportEncoder` makes the bytes through Vixen, and `ExportRun` makes and delivers an export's object. `Builds` holds the pipeline, for a Server's job and for `patina build`, and the journal that makes one resumable (ADR 0011). There is no codec or baking here (plan §4).

# Changelog

Notable changes to Patina. The format follows [Keep a Changelog](https://keepachangelog.com/en/1.1.0/), and versions
follow [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [Unreleased]

### Added

- Fill past the dilation, a switch in the Bake dialog (#148): the texture past each chart's dilation is filled with a smooth blend of the maps around it, so its smallest mipmaps keep the maps' own values instead of fading to the empty background. Nothing the charts or the dilation wrote changes, and the ID, UV Islands and UV Borders maps keep their background. Through the API the bake option `diffusion`.
- A UV Borders map to bake (#121), with a section in the Bake dialog: black on the border of each UV island of the low mesh and rising evenly to white a width inside it, measured along the UV layout, to fade a pattern out before the seam it would break at. A graph's Mesh Map node reads it. Through the API the bake options take the map `borders` and `borders.width`, a share of the texture.
- The Edges map can mark the low mesh's edges (#278): Mesh, in its section of the Bake dialog, is High mesh, the edges where the rays land, as before, or Low mesh, the low mesh's own hard or sharp edges, so a low poly's edges get a band even under a high mesh that rounds them all. Through the API `edges.mesh`, `high` or `low`.
- Choosing another UV set in Properties carries a texture set's paint into the new layout (#210), so it stays where it is on the model: each canvas, a layer's, its mask's and its mask entries', is laid out again from the surface, as Preserve Paint does for a new mesh, in one undo step that gives the old canvases back. A Paint stays switch beside the UV set leaves the paint on the map instead. Through the API a `carryPaint` command takes the UV set the paint was laid out in.
- A tileable bake (#212): with Tileable on in the Bake pane, the high mesh is laid again on each side of the low patch, so a high-poly patch bakes to maps that repeat without a seam. Through the API `tileable` in the bake's options.
- Merge into one set of files writes sets on several UDIM tiles as one set of files per tile when every file's name says its tile with `{udim}` or `{tile}` (#281), so a model with a material per tile exports as UDIM files. Without either in the names it still writes the sets one by one, and now says what to add.
- The Texture Sets pane shows the open set's UDIM tile beside its size when it is not 1001, and a preset's file list names each set by its own tile, where it always said 1001 (#281). Through the API a stack's state has `udim`.
- A stroke in the 2D view paints a layer that holds more texels than its texture set at the layer's own size (#19, #281), as a stroke on the model already did, so a set made smaller to work faster can be painted in either view. Only a layer of another shape than the set is still refused.
- Import Materials reads an OBJ's and an FBX's opacity (#280): an OBJ's `d` and `map_d`, and an FBX's opacity and transparency picture, make the graph's opacity map, its own picture read in red times the factor, or the base color's alpha when it is the same picture. And a placed glTF picture wraps as its sampler says: Clamp and Mirror reach the Transform 2D's Tiling, where every placement repeated before; a picture that wraps differently across and down repeats and is named in the warnings.
- A build's report lists every project it selected, a fresh one as already up to date with the digests of the files already delivered (#280), so comparing two builds says a project the later build found fresh is the same, where it said the later build had removed its files. The totals still count only what the build did. Each delivery keeps its files' digests beside them, so a fresh export's files are not read again.
- Patina reads lossless WebP pictures (#156): a graph's Bitmap, a brush's alpha, a bake's color source, the viewport and a picture preview take a `.webp`, and an exported WebP reads back as the picture it was. A lossy or animated WebP is refused with what it is.
- A preset's own size computes a project's graphs at it (#280, ADR 0028), where they were computed at their own size and the files resampled, enlarged if the preset was larger. It holds when every preset the project exports through names the same size; presets that disagree still resample.
- The 2D View's histogram is the picture's own (#172): the engine counts the node's picture at the size the graph computes it, on the GPU, for red, green, blue, alpha and luma, where it counted the 256-pixel reduction in the editor. The label says the picture's size. Through the API `POST /api/v1/graphs/{id}/histogram` answers with 256 shares of the picture's texels per channel.
- Copy Values and Paste Values, on a node's right-click menu (#181): Copy Values remembers the numbers, settings and expressions of one node, and Paste Values gives every chosen node of the same type the same, the defaults included, as one undo step. It works across graphs on screen.
- Expose All, in the Inspector of a node with more than one thing to expose (#181): each number, choice and color on the node that no wire, expression or parameter drives becomes a parameter of the graph, each named after its field and apart from the others, as one undo step.
- Copy Image, in the 2D View's toolbar (#184): puts the node's picture on the clipboard as a PNG, at the size the graph computes it once that has come.
- Timings on Cards, in the Graph menu and the Arrange menu (#182): each node shows how long it took on the GPU the last time it ran, kept while the result cache answers for it. Times overlap on a GPU, so they compare nodes rather than add up to the evaluation. Through the API a graph's state and each evaluation carry `times`.
- A compound's Color parameter can follow the one around it (#272): a compound inside a compound set to `$Tint` takes the outer compound's Color parameter `Tint`, as a Text parameter's `$` reference does. Arithmetic over a color, such as `tint * 0.5`, is refused with a sentence that says a color can't be computed with, instead of an unknown name.
- Warp to Geometry follows a surface that turns away on both sides, such as round a cylinder (#263): it measures along the decal's own facing rather than the camera's rays, so it works from any view, in one round trip rather than one per place, and makes a 5 by 5 warp grid where it made a 3 by 3, so each quarter of the picture covers as much of the surface. The Warp handles show whichever grid the decal has. A decal's warp is now any square grid of 2 to 9 points on a side. Through the API `POST /api/v1/viewport/cast` casts up to 1024 rays along one direction at the open mesh, refused with `viewport-cast-refused` or `viewport-mesh-unavailable`.
- `patina library check` lists the bytes under `.revisions/` that no snapshot and no pin names any more, as a deleted snapshot or document leaves them, with how large each is; `--purge-revisions` removes them, and refuses while a Server has the library open (#270).
- Three more maps to bake (#148, #121), each with a section in the Bake dialog: Opacity, white where a ray found the high mesh and black where it found none, the alpha of a card baked from leaves, strands or a fence; Edges, a band along the high mesh's hard edges, or its edges sharper than an angle, white on the edge and fading across a width, for wear that follows edges even on a low poly baked onto itself, whose curvature is flat; and UV Islands, a flat color per island of the low mesh's layout, never blended at a border. A graph's Mesh Map node and a mesh-map mask read all three. Through the API the bake options take the maps `opacity`, `edges` and `islands`, and `edges` for the band.
- A rounded edge has a profile (#214): Round turns the normal evenly across the bevel as before, Smooth keeps the bevel's sides soft, and Chamfer makes it one flat face at the halfway angle. The Edges map takes the same profile. Through the API `rounding.profile` and `edges.profile`.
- The curvature map has a range (#148): Automatic, as before, spreads each mesh's own bends over the whole range, and Custom makes a bend as tight as a radius white, or black for a crease, so curvature maps of different meshes agree. Through the API `curvature.range` and `curvature.radius`.
- UDIM, a tile per texture set (#20): a material laid out wholly on one UDIM tile other than 1001 paints, picks, bakes, checks, pads and exports as that tile, its layout read moved home onto 1001 wherever Patina reads it, so a model with a material on each tile works as a set per tile. A preset's `{udim}` and `{tile}` name the set's own tile (`1002`, `u2_v1`) where they always said 1001. A set reaching several tiles is still said out loud and its bake refused, now with "Give each tile a material of its own" as a way out, and Merge into one set of files writes sets on different tiles one by one and says why.
- Apply to All Sets, beside Add and Remove Channel in Properties' Document section (#141): every other texture set of the model gains the channels this one has and it lacks, each starting as Add Channel starts one, and the section says what each set gained. A set open in a session takes them as one undo step, unsaved; a set nobody has open has them written to its file. Nothing is taken off a set. Through the API `POST /api/v1/stacks/{id}/channels/apply-to-all`.
- A layer that holds more texels than its texture set is painted on the model at its own size (#19), so a set made smaller to work faster keeps every layer's detail and goes on being painted. A brush sized in texels keeps its size on the model. A stroke in the 2D View, whose stamps are the set's texels, is still refused for such a layer, and now says to paint it on the model.
- The palette and the Nodes list show each node drawn small (#183, #38): the engine draws every node type once at its defaults, with a noise on its picture inputs, and keeps the picture in the cache until Patina or a compound it is made of changes. A node with no picture, such as an Output, keeps its name alone. Through the API `POST /api/v1/graphs/{id}/node-types/thumbnails` names each type's picture by hash under `/previews`.
- Keep Aspect on Shape (#96, ADR 0028): on an image that is not square, the shape is drawn in a square of the shorter side and repeated along the longer one, so a disc on 2048 × 1024 is two round discs and the image still tiles. Off, the shape stretches with the image, as before.
- Hydraulic Erosion, under Surface (#218): rain runs down a height map, wearing its slopes and laying silt where the water slows, with Rain, Evaporation, Capacity, Erosion, Deposition and a step count; ground is moved and never made or lost. A second output, Water, says where water stands at the end, for wet or silted ground. It does not yet cut long branching channels.
- Graphs that make environments (#180), under the new Environment group: Sky draws a clear daylight sky as a panorama from the sun's position and the haze, with a sun and a ground; Panorama Rotate turns a panorama about the vertical, tips or rolls it; Panorama Light adds a round light at a direction; and Horizon replaces the ground below a horizon with a color. Exposure, under Color, brightens or darkens a picture by stops without clipping.
- Crystal, under Noise (#42): faceted shards, each a tone of its own falling away in flat planes, finer shards over coarser.
- A Pixel Processor's expression can read its inputs' neighbours (#42): `ReadA(coord + int2(1, 0))` is the texel to the right, wrapping round the edges when the graph tiles.
- Import Materials brings more of a glTF material in (#157): its emissive factor and `KHR_materials_emissive_strength` scale the emission, and a material with an emissive factor and no picture glows with it; a material whose alpha is masked or blended gets an opacity map from its base color's alpha and factor; and a picture with a `KHR_texture_transform` is placed by a Transform 2D after it, moved, turned and scaled as the file says. A picture read through a second coordinate set and a mask's cutoff are named in the warnings. A glTF material with no emissive factor has no emission, as glTF says.
- Editing a hand-written export preset in Edit Presets… keeps its comments (#155): the block at the top, and the lines above a field or above a texture, found again by its file name, even across a rename. A comment inside a texture is still lost.
- What differs between two builds (#217): `GET /api/v1/builds/{id}/compare?before=<earlier>` and `patina build compare <earlier> <later>` list, project by project, each output whose build key changed and each exported file that was added, removed, changed or is byte for byte the same. A build now keeps each delivered file's SHA-256 in its report, so the comparison holds after the later build has written over the earlier one's files.

- A start with no library no longer logs refused requests: the Library and its costs wait for the engine to say it has one (#192).
- Autosave says what it did (#192): each time it keeps a document's unsaved edits, Activity lists that it did, and when it cannot, Activity says why and counts it among the problems. Through the API a graph's and a stack's events include `autosaved`, and `autosaveFailed` with the reason as its label.
- A document saved by a newer version of Patina is not opened, with a message that says so (#162): saving it here would write it back at this version's format and lose what is new. The file is left as it is. Through the API opening it is refused with `document-newer`, naming the file's format and the newest this build reads.
- A document with many layers is quicker to set up (#208). The pause button in the Layers bar holds evaluation while you add and arrange layers: edits are taken and undoable as ever, the picture stays as it was, and the bar says Paused, with edits waiting, until a resume evaluates them all at once. Proxy beside it composites the picture at Half, Quarter or Eighth size while you work, so fills and filters run on a fraction of the texels; strokes still land at full resolution. Neither is saved in the document, and saving, autosave, exporting, checks and the picker always read it whole, at full size. Through the API `PUT /api/v1/stacks/{id}/pace`, refused with `stack-proxy-refused`; the state's `pace` says how it is set and every client hears a `paced` event (ADR 0036).
- A quick mask (#127): Quick Mask (T, and the button under the viewport's tools) turns it on, and strokes then paint it, shown red over the model in every view, rather than the layer; pressed again it applies, and every stroke after is kept to what was painted on it, whatever the tool, through the brush, a fill, a line or a path, in the viewport or the 2D view. Invert Quick Mask (Y) keeps strokes outside it instead, and Clear Quick Mask takes it off and starts the next one empty. It is the session's: the journal paints it, so a lost Worker paints it again, and no save writes it. Through the API a stroke's `quickMask` is `paint`, `inside` or `outside`, and `GET` and `PUT /api/v1/stacks/{id}/quick-mask` show, hide or clear it.
- The viewport draws where a mirror symmetry's plane meets the model (#132): a cyan line across the surface, hidden where the model hides it and left off parts isolated away, beside the plane across the model's box. Through the API `PUT /api/v1/viewport/symmetry` draws it for every client, and the viewport's state says which symmetry it draws.
- Lines and paths follow the pen's tilt and twist as a free stroke does (#123), faded between their points the short way round, as well as its pressure.
- Snapshots (#209), under the undo history: Take Snapshot keeps the document in front as it is saved, its paint with it, under a name, and Restore puts it back. A snapshot outlives closing the document and travels with the library: it is listed in `.snapshots/` beside the document and its bytes kept under `.revisions/`, where an unchanged paint file costs nothing more. Restoring first keeps how the document stood as a snapshot of its own, so it can be taken back. Through the API `GET`, `POST` and `DELETE /api/v1/library/snapshots` and `POST /api/v1/library/snapshots/restore`, refused with `snapshot-unsaved` or `snapshot-document-open`.
- A sample to start from (#190, #34): Start's Samples copy **Knot**, a gold knot around a red sphere, into the library as a project of your own and open it. Its mesh is laid out already, and each of its two texture sets has a few layers whose masks are Patina's own grunges, so it draws with no bake. It is CC0, in `content/samples`. Through the API `GET` and `POST /api/v1/library/samples`.
- What the library costs (#207), in the Inspector while nothing in the Library is chosen: each folder's and project's documents' maps, uncompressed at each document's size, costliest first, with a click going into a folder; and below it the documents there over a budget of 4 to 256 MB. The scan keeps each stack's size and map count in the index, which is rebuilt once for it, so neither opens a document. Through the API `GET /api/v1/library/costs` and `GET /api/v1/library/costs/documents`.
- Eight more starter materials on the shelf and in New Graph's templates (#34): Clay, Concrete, Copper, Dark Iron, Gold Leaf, Plaster, Rubber and Sand, CC0 like the rest of `content/`.
- Properties' Document and Brush sections fold to their headings, and stay folded on this machine, so a layer's settings and its mask come up the pane (#201).
- About names the Vixen version the engine runs on, with its commit. Through the API `GET /api/v1/system` says `vixen`.
- Choose Picture…, beside Alpha in the brush panel, makes any picture the library reads a brush's alpha (#122): it is brought into the project, and each stamp lays down its opacity where the picture has any clear texels, or its brightness where it has none, so a shape drawn on a clear ground paints its shape whatever its colour. An alpha was a PNG's red before.
- A layer's instances in the model's other texture sets are listed in its Properties beside those in its own set, each with the set it is in and a Go that opens that set on it, and an instance of a layer in another set says the source's name rather than its id (#108). Through the API `GET /api/v1/stacks/{id}/instances` lists both ways, from open sets as they stand and from the others' files.
- Pointing at a texture set in Texture Sets, or at a part in its Isolate parts list, marks it on the model (#136): its faces washed orange with their outline drawn round them, over the material as it is shaded, until the pointer leaves the row. A part shown alone elsewhere is not marked where it is hidden. Through the API `PUT /api/v1/viewport/highlight` marks named meshes and materials for every client, and the viewport's state says what is marked.
- A graph's parameter can be a color (#181). Color is a kind beside Float, Int, Bool and Text in Graph Settings, edited with a picker and a float for each lane, so a value above one is kept. The Expose button beside a color input in the Inspector makes a Color parameter from the color it holds and drives the input from it, and the `=` box beside it takes a Color parameter's name. A compound's Color parameter shows as a picker on its node, in a layer's Properties and in presets, and `patina bake --param Tint=0.8,0.4,0.1,1` sets one. A color is written as three or four numbers separated by commas. A Color parameter fills a color input whose expression is its name alone; arithmetic over a color is refused, as is a number written on a compound's color input.
- Ten more grunges (#169), each tiling and with Scale and Amount, and Contrast where it has edges: Concrete Pores, Cracked Paint, Fine Scratches, Mould Spots, Oil Stains, Rain Streaks, Rust Spots, Sandblasted, Smudges and Wiped Grime.
- Weathering by material (#177), each a filter that writes every channel it touches at once from the bake: Worn Metal (a coat rubbed through to bare metal on the edges, grime in the hollows, an uneven tarnish), Worn Leather (dye scuffed pale on the edges, dark dry creases, handled faces burnished), Worn Fabric (rubbed pale on raised parts and seams, unevenly bleached, dirty folds) and Weathered Rock (fresh chips on the edges, soil in the cracks, lichen on the faces turned to the sky).
- Anisotropic Painterly Smooth, under Filters (#119): Painterly Smooth's strokes stretched along the picture's own edges, so a curve stays a curve. Oil Paint is built on it now.
- Environment Light, under Surface, and Environment Lighting, under Stylised (#119): the diffuse light a picture of the surroundings, equirectangular, casts on a normal map or on the bake's world normal, to paint into a colour; Environment Lighting does that to the base colour with the occlusion and an optional toon banding.
- Fill Holes, under Photo (#178): the masked part of a picture filled from what surrounds it, for a seam, a shadow, a hand or a logo to paint out. Fix Seams fills a band along each edge from both sides of the wrap so a photo tiles, and Clone Patch copies a round patch of the photo from one place over another.
- `patina-bench panel-pair` writes a plate cut into panels over a one-chart low, so an id bake and Shut Lines can be judged where parts meet inside a chart (#118).
- The brush under the pointer shows its stamp (#137): the viewport's ring becomes the brush's own stamp, its alpha, angle and stretch, drawn by the engine as one dab with nothing random, once the brush is large enough on the screen to read; a small brush keeps the ring. The 2D view shows the brush under the pointer too, at its size as the map is drawn. Through the API `POST /api/v1/stacks/{id}/brush-preview?stamp=true` draws the stamp.
- A 3D mouse turns the viewport (#163): with a 3Dconnexion device plugged in, twisting or tipping the cap turns the model, sliding it slides the model, and pushing it away or pulling it back zooms, for as long as the cap is held; the first button frames the model. The desktop app reads the device's own reports, so no vendor driver or SDK is needed (ADR 0034).
- The projection tool projects a material (#128): with a material from the shelf in the brush panel, it paints every channel the layer writes from the material's maps, fixed on the view where its frame stands, moved, scaled and turned by the same handles and keys as a picture, and tiled or not. A stencil still masks it. Through the API a stroke's material source takes a `frame`.
- The projection tool and stencils work in the 2D view (#128): the picture, or the projected material, is drawn over the 2D view at the same place on the screen as over the viewport, and a stroke there reads it where each texel is drawn, at any zoom or pan. The stencil's keys work with the 2D view focused too.
- A picture dropped on the mesh becomes a decal there: from this machine or from the library tree, it is brought into the project and laid on a new fill on top, facing out of the face it landed on, at the picture's own shape, colouring only the base color. The layer and its decal undo as two steps.
- Warp to Geometry, beside Warp in a decal's properties, measures the surface under the decal as the viewport sees it and moves the warp grid's middle row and column so each half of the picture covers as much of the surface: a decal across a bend is no longer stretched over the side that turns away. It is one edit, and Straighten undoes it.
- Favourites on the shelf (#203): the star beside a material keeps it at the top of the shelf, and From Favourites lists the starred ones alone, from wherever they are. The stars are this machine's, kept in the app's preferences with the starred nodes.
- New Project starts a texturing project or a layered material wider than it is tall (#144): Height, beside Size, is Same as width by default, so a model laid out on a 2:1 sheet paints at 2048 × 1024 from the start. A graph stays square. Through the API `POST /api/v1/library/projects` and `POST /api/v1/library/project/documents` take `rows`.
- Remove Channel…, beside Add Channel… in Properties, takes a channel off the texture set as one undo step: no layer writes it and no export finds it. The layers keep what they held for it, their values and paint, so adding the channel again brings it back as it was. A set keeps at least one channel. Through the API the stack command `removeChannel`, refused with `channel-missing` or `channel-last`.
- A layer, a mask, an image material and a graph's Bitmap read TIFF pictures (`.tif`, `.tiff`), so the library, the picker and Import Materials offer them: an 8-bit TIFF is read as a PNG is, and a 16-bit or float one at its own depth, as a 16-bit PNG or an EXR is. Tiled, LZW and JPEG-compressed TIFFs are refused with what they are.
- A brush follows a pen's tilt and rotation. Rotation in the brush panel takes Pen Rotation, which turns each stamp with the pen's barrel, and Pen Tilt, which turns it the way the pen leans; either turns the whole stamp from its angle, its stretch with it, so a chisel follows the pen. Tilt to size makes a pen held upright paint smaller and one laid over paint the whole size, as a pencil's side does. A mouse is an upright pen. Brushes and `.ptbrush` presets keep both. Through the API each stamp takes `tilt`, `azimuth` and `twist`, and a brush takes `tiltSize` and the rotations `pen` and `tilt`.
- Brush Presets, a type on the material shelf: the starter presets, the project's own and other projects', found by name, tool or project like anything else there. A click takes one up, as it does in the brush panel. Through the API `GET /api/v1/library/materials` lists them with the role `preset`, tagged with their tool.
- Three nodes that trace rays over a height field, under Surface: Traced Occlusion, the share of the sky each texel sees (a gap under a ledge lets light in, which Ambient Occlusion cannot see); Bent Normal, the direction that open sky lies in, as a normal map; and Irradiance, the light the rays bring back from a Sky colour and, where a ray strikes, from a Light map wired in, such as a lit wall throwing colour onto the ground beside it. Traced Occlusion is also a layer filter.
- Volume Noise, Volume Mask and Volume Gradient read the bake's position map when nothing is wired into Position, so they work on a mesh as soon as they are added.
- Six more surface finishes under Finishes, each a filter that writes several channels at once: Galvanised (a patchwork of zinc crystals, each with its own tone, sheen and tilt), Grainy (an even blasted tooth with no direction), Ground (crossing curved sweeps from a grinding disc), Perforated (round holes in staggered rows, through the height and clear in the opacity, which it replaces), Raw (cloudy patches of darker, duller mill scale) and Rough (lumps at every size, worn smoother on top). Pixelate, under Adjust, cuts a picture into any number of flat blocks across and down, not only powers of two. Smooth Bevel, under Surface, is Bevel Height with its corners and ridges rounded.
- A mask's generators fill a layer's content too: a graph fill offers Dirt, Metal Edge Wear and the other generators after the shelf's graphs, with their knobs in Properties. A generator layer inside a mask has its knobs in Properties as the mask's own generator does, and a generator of the project's own shows its knobs, not only a shipped one.
- A filter reads a channel the texture set does not have as that channel would stand untouched: whole opacity and occlusion, no metal or light, a flat normal, and a mid grey for the rest. So Perforated cuts its holes into the opacity beneath, leaving a half-clear sheet half clear between them.
- Six more surface finishes under Finishes, each a filter that writes several channels at once: Galvanised (a patchwork of zinc crystals, each with its own tone, sheen and tilt), Grainy (an even blasted tooth with no direction), Ground (crossing curved sweeps from a grinding disc), Perforated (round holes in staggered rows, through the height and clear in the opacity), Raw (cloudy patches of darker, duller mill scale) and Rough (lumps at every size, worn smoother on top). Pixelate, under Adjust, cuts a picture into any number of flat blocks across and down, not only powers of two. Smooth Bevel, under Surface, is Bevel Height with its corners and ridges rounded.
- The Export dialog's Document scope exports a graph that its project does not ship, such as a graph in a texturing project or a mask graph, on its own: it is a texture set of its own, its files carry its name so they never take the name of one of the project's, and the project's other files in that folder stay. Through the API `POST /api/v1/builds` takes `documents`, and `patina build` takes `--document <file>`.
- Merge into one set of files, under the Export dialog's texture sets: sets that share one UV square, as a model's parts often do, are written as one atlas, each set where its layout puts it. Overlapping layouts and a set on no mesh are reported. The project keeps the choice. Through the API `options.merge`, and `patina build --merge`.
- Each engine's starter preset is checked against what its engine reads in every lane, and every DDS and KTX2 file an export writes against Microsoft's and Khronos's layouts, with no engine installed.
- A bake can be wider than it is tall: Height beside Size in the Bake dialog, Same as width by default, so a texture set authored at 2048 × 1024 bakes its maps at that shape. Through the API the bake options take `rows`, and each baked map says its `rows` when it is not square.
- The position map has a range, in its section of the Bake dialog: Box stretches each axis across the high mesh's bounding box as before, Cube keeps its proportions so a distance reads alike on every axis, Sphere is centred on the middle of the mesh, and None keeps model units for an EXR. Through the API the bake options take `position.range`.
- Wires move and copy by hand in the graph. Shift-drag from an output onto another node moves every wire it had to that node's output of the same kind; Shift-drag from a wired input to another input moves its wire there, and Ctrl-drag (Cmd on a Mac) copies it, so both inputs read the same picture. Swap Inputs, in a node's right-click menu and the Graph menu, trades the wires into a node's first two inputs of one kind, such as a blend's two pictures. Each is one undo step.
- Parameters on Cards, in the graph's Arrange menu and the Graph menu: each node lists what was changed on it from its type's defaults, up to four lines, an expression shown as it is written. The choice is kept in the app's preferences.

- The 2D view draws the texture set's UV layout over the map (UV, at its top right), each edge once, a light line over a dark one so it reads on any map; Fit shows the whole map again after zooming and panning; the corners say which way U and V run and that the map is UDIM tile 1001; and the pointer's UV and texel are read out at the bottom. Through the API `GET /api/v1/stacks/{id}/uv-wire` gives the layout as an SVG over the unit square, drawn by the engine from the mesh.
- A texture set's menu, on a right-click in Texture Sets or the Menu key: Paint it, Show Alone or Show the Whole Model, and Bake…, Export… and Project Settings….
- Depth of field in the viewport: Depth of field and Focus in the Display panel's Finish section. ### Fixed

- Restoring a snapshot, or taking one, of a document with edits just made no longer fails without saying why (#284): the engine is asked whether the document has unsaved edits, rather than trusting a tab that had not caught up, and they are saved first.
- Saving a picture, a graph or the engine's shader caches no longer fails on Windows while the engine's shared graph and paint code is reading the file (#277): every read there lets another program write or delete the file meanwhile, as Patina's own reads already did.
- Saving, autosaving, restoring a snapshot and reading a layer stack's pixels no longer fail with "No GPU process reached this stack" when the GPU is merely slow (#275): they wait for as long as a GPU process is connected and working, and give up only when none comes. The stack they wait on is evaluated before other open documents.
- A stroke while the document composites at a proxy is repaired over the tiles it touched, as at full size, rather than running every layer above it whole (#279).
- A layered material written by a newer build of Patina is refused by the Worker and by `patina build` as well as by the Server, so nothing reads it as far as it goes and writes it back without what was new (#279).

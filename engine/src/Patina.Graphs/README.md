What a graph's references mean to Patina, for every process that evaluates one: compounds from the folder beside it, and
bitmaps from paths relative to it and to the library (ADR 0007). The Worker and `patina bake` both read a graph through
this, so a graph that previews also bakes. Everything general lives in Vixen; what is here is the library's layout.

`GraphSize` is how big a graph is made, for the same processes and for a build (ADR 0014).
